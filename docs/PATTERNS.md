# PATTERNS.md — Code Patterns & Conventions

> This file is read by Claude Code and review agents. It defines how things are done in this codebase.
> Start empty. Add patterns as they emerge during development.
> Every entry should include: the pattern, when to use it, an example, and when NOT to use it.

## How to Add a Pattern

When you solve something well or learn from a bug, add it here:

```markdown
### Pattern Name
**When to use:** [situation]
**Pattern:** [what to do]
**Example:** [code or description]
**Don't use when:** [exceptions]
**Added:** [date] — [why this was added]
```
